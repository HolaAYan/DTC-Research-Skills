# Evidence & Data Integrity Rules（数据与证据红线 · 详细版）

本文件是 skill 的最高优先级约束，适用于研究的每一步与输出的每一句话。

## 1. Accuracy First — 准确性优先

### 1.1 严禁行为清单

- 编造数据（Revenue / Sales / Traffic / Share / Funding / ROAS / CVR / 销量等一切数字）
- 根据经验猜测数据
- 为了让报告看起来完整而补充不存在的信息
- 把 AI 推测写成事实
- 把第三方估算数据伪装成官方数据
- 把流量、粉丝、搜索量等指标直接等同于收入或市场份额

如果找不到可靠公开数据，**明确写**：

> No reliable public data found.

不要猜测，不要用行业平均值填充，不要用相似品牌的数据替代。

### 1.2 每个数据点都要有来源

所有重要定量数据必须给出来源，包括但不限于：
Revenue / Funding / Market size / Market share / Website traffic / Followers / Reviews / Rating / Price / SKU 数量 / Campaign results / Crowdfunding results / Creator 数据。

动态数据尽可能标注：

> As of YYYY-MM-DD

（使用当前对话日期的真实日历日，不臆造日期。）

### 1.3 区分「事实证据」与「分析判断」

每条重要结论标注证据分级：

| 标签 | 含义 | 何时使用 |
|---|---|---|
| **FACT** | 来源明确、可直接验证的事实 | 官网、财报、新闻稿、平台数据页直接支持 |
| **OBSERVATION** | 从公开页面、数据或多个事实中观察到的现象 | 首页结构、社媒内容主题、评论中的重复主题 |
| **INFERENCE** | 基于事实和观察进行的分析判断 | "该功能说明其主推 X 人群"之类 |
| **UNKNOWN** | 没有足够可靠的公开信息 | 不能确认的事项 |
| ESTIMATE（扩展） | 第三方估算值 | Similarweb 流量、市占率估算等；仍需给出来源并标注 Estimated |
| HYPOTHESIS（扩展） | 当前无法验证的合理可能性 | 明确的推测，绝不写成事实 |

**规则**：允许分析推断，但推断与假设绝不表述为事实。宁可写 UNKNOWN。

## 2. Source Hierarchy — 信源优先级

优先使用：

### Tier 1 — First-party 一手信源
- 官网 / 官方社媒 / 公司报告 / 投资者材料 / 官方新闻稿
- 创始人访谈 / 演讲 / Podcast / 自媒体内容
- 官方 Campaign 页面

### Tier 2 — Platforms / Databases 平台与数据库
- Similarweb / Modash / Trustpilot / Kickstarter / Indiegogo
- Google Trends / Meta Ad Library / Google Ads Transparency 等

（根据研究项目选用；Tier 2 数据多为估算或平台记录，需标注口径。）

### Tier 3 — Authoritative Media 权威媒体
- Reuters / Bloomberg / Forbes / CNBC / TechCrunch / 可信行业媒体

### Tier 4 — Community 社区
- Reddit / 论坛 / YouTube 评论区 / 其他公开社区

**Tier 4 使用限制**：社区内容**只用于**理解 Customer Voice / Pain Points / Purchase Motivation / User Experience。
不能把个别用户评论当作整体用户事实；必须归纳重复出现的主题并说明样本性质。

### Geographic Relevance — 地理相关性（与 Tier 并列的第二维度）

信源判断采用**两个独立维度**，不得互相替代：

- **Source Reliability（来源可靠性）**：即上面的 Tier 1–4。
- **Geographic Relevance（地理相关性）**：来源与**目标市场**（见 §6）的贴近程度。

**地理相关性优先顺序**（只表达"离目标市场多近"，不代表可靠性高低）：

1. 目标市场区域官网及官方区域页面
2. 目标市场官方社交媒体账号
3. 目标市场本地数据平台及行业数据库
4. 目标市场本地评论、社区及用户反馈平台
5. 独立国际媒体及权威行业媒体
6. 中文媒体及中文互联网资料

**规则：**

- 本顺序**不取代** Tier 1–4。两个维度须**分别标注、分别判断**——一个来源"属于目标市场"**不等于**它比别的来源更可靠。
- 中文资料可作**补充**（尤其公司背景 / 制造 / 供应链 / 创始人访谈等原始信息）；但**不得**仅因检索方便就优先使用中文二手报道。
- 若海外原始来源可以获得，**优先引用原始来源**；二手报道尽量回溯到原始出处。

### 2.x 同一指标多口径并存时（**择新取一 · 并列呈现**）

同一指标（典型：站点流量来源结构）常同时拿到多个平台 / 多个月份的口径，且数字可能相差极大。处理规则：

1. **分析基准只有一个**：取 **`一手平台数据` 且 `数据月最新`** 的那一条（如平台官网 overview 页直读的数字）。所有结论、诊断、机会、优先级一律基于它。
2. **其余口径降级为"参照"**：二手转述（媒体引用平台截图）、数据月明显偏早、来源无法回溯的口径，**全部并列列出**（不得因为"看起来矛盾"就删掉），但**只作参照，不用于分析判断**。
3. **口径差异归因于方法，不归因于品牌**：差异说明写进 **方法论注释 / 研究局限**；**不得**进入 Executive Summary 的"关键发现"，也**不得**写成品牌痛点或优势——那是测量问题，不是品牌的问题。
4. **数据必须真实可溯源**：不虚构；二手转述不得当一手使用；取不到一手时如实写明"该维度仅得二手口径"。
5. **不完整是正常结果**：某口径只公开 1–2 个维度就只呈现这 1–2 个，**不为凑数补位、不反推**。

> 判定"哪一条是一手"的实操：**URL 是否指向平台自身的官方数据页**（semrush.com/website/… 、similarweb.com/website/…），页面是否标注 `last updated` / 数据月。落在媒体或第三方博客里的平台截图 = 二手转述。

## 3. Citation Requirements — 引用要求

- 重要事实和数据必须在对应内容旁给出来源（紧邻声明，不集中在文末列表）。
- 来源尽量直接指向：**具体页面 / 具体报告 / 具体文章 / 具体平台数据**，而不是网站首页。
- 动态数据标注查询日期（As of YYYY-MM-DD）。
- 第三方估算 → 明确标注 `Estimated` + 来源。
- AI 判断 → 明确标注 `Inference`。
- 引用新闻报道时，**它证明了什么就只用它证明什么**，不扩大解读范围。
- 不要列从未用过的来源；不要引用不支持该 claim 的来源。

**引用示例：**

> 该品牌于 2016 年由创始人 X 创立。FACT [官网 About 页: https://…]
>
> 预估月访问量约 120 万。ESTIMATE [Similarweb，As of 2026-09-08]
>
> 官网首页主推 3 款旗舰产品。OBSERVATION [首页: https://…]
>
> 从评论区重复出现的"安装困难"主题看，新手安装是其核心痛点。INFERENCE [基于 5 条独立 Reddit 评论，As of 2026-09-08]

## 4. Missing Data Rules — 缺失数据处理

- 无可靠公开信息 → 明确写 `No reliable public data found.`
- 不猜测、不补行业平均、不用类似品牌数据替代、不根据流量猜收入、不根据粉丝猜销售额、不根据社媒热度猜市场份额。
- 可引用相关新闻/访谈作为背景证据，但必须严格限制在报道实际证明的范围内。

## 5. 额外纪律

- 不调用内部没有的能力假设数据（如 CRM/邮件后台/转化率后台）——只能分析**实际观察到的公开页面**。
- 无后台证据时，不得推断真实留存率、复购率、LTV、广告预算、ROAS。
- 广告存在 ≠ 知道预算/ROAS/销售额；单一渠道使用 ≠ 该渠道是"主增长渠道"（需多重证据支持）。

## 6. Market Scope — 研究市场判定与区域数据

本节的判定在研究开始前即生效；结论须体现在报告的 **Source Map A 小节**（见 `output.md`）。

### 6.1 主要市场判定（四步优先级）

1. **优先**使用可靠的**区域营收 / 销售数据**判断主要市场。
2. 若无区域营收数据，再参考**其他可靠的地理业务指标**（已披露的区域用户数、区域渠道规模等）。
3. 若仍无法判断，**默认以北美作为研究市场**。
4. 必须区分「**已验证的主要市场**（verified）」与「**默认研究市场**（default）」——**不得**把默认北美写成品牌真实的最大市场。

- 判定结论、依据与 **Market Status**（verified / default）都要写入 Source Map A 小节。
- 无法确定时写明：`Primary market not reliably established; North America used as the default research market.`
- **不强制**每个品牌都必须拿到区域营收或市场份额数据；拿不到就按上述流程降级并标注。

### 6.2 区域数据与全球数据

- **区域数据**（某市场的价格、竞品、评论、流量、份额）与**全球数据**必须**分别标注**，不得直接混用。
- **全球市场份额不得直接与单一区域市场份额比较**；若必须并列，须说明口径差异。
- 缺少同市场数据时，**明确标注数据范围与局限性**，**不得**用其他市场的数据冒充目标市场数据。
